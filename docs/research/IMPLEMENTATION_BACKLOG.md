## What “100% code completion” means

The implementation pass is complete when every code-bearing deliverable in Sections 1–10 is implemented, connected to its real CLI/storage/evaluation path, documented, and has regression definitions. We then run one consolidated validation campaign (test suite, Ruff, formatting, mypy, build, and targeted native checks), repair all findings, and only after that begin separately gated scientific/data qualification. Writing a test is implementation; executing it belongs to validation. No finite ray/sample budget is ground truth.

The larger research mission cannot be completed by code alone. Scientific admission still requires qualified measurement/evidence, trusted external review, and passing criterion-driven experiments. Production RT corpus generation and advanced model training remain gated until their applicable criteria pass.
