## Question

Do the native Sionna 2.2.0 CDL-A–E diffuse ray-angle draws reproduce the
first- and second-harmonic complex characteristic values of each individual
AoA, AoD, ZoA, and ZoD marginal derived independently from the SHA-pinned
TR 38.901 v19.2 profile tables?

## Frozen design

- Profiles: CDL-A, CDL-B, CDL-C, CDL-D, and CDL-E.
- Independent draws: 8,192 per profile, generated by the native CPU CDL
  implementation with seed `250000 + ord(profile_letter)`.
- Claims: positive Fourier harmonics 1 and 2 for each of the four angle
  marginals; real and imaginary components form one 80-claim family.
- Family-wise error: two-sided Bonferroni-adjusted normal intervals at
  family-wise alpha 0.01, using the empirical standard error across
  independent channel draws.
- Precision limit: every component's simultaneous interval half-width must
  be at most 0.05.
- Acceptance: every component interval contains the table-derived complex
  characteristic value and satisfies the precision limit. No seed, profile,
  harmonic, threshold, or multiplicity correction may change after observing
  outcomes.

## Analysis and scope

Within each diffuse cluster, the reference averages the 20 table-derived ray
atoms for the selected angle and harmonic; it then weights clusters by their
normalized profile powers. The native statistic uses the generated ray angles
and cluster powers, first normalizing total diffuse power within each draw.
LOS specular components are excluded from this diffuse marginal comparison.

The test implementation is
`tests/test_integrations/test_g4_cdl_joint_angular_characteristic_native.py`.
Before executing it, scan the saved result corpus for the exact structured seed
keys and retain the scan outcome with the run record. A pass would support only
these eight low-order marginal characteristics for the pinned tables and
native implementation; it would not establish the full angular distribution,
arbitrary orientation/pattern behavior, geometric RT validity, or measured
channel accuracy.
