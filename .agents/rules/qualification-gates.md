# Qualification gates

Engineering checks prove software behavior within their named scope. Scientific qualification requires the exact governing protocol and independent evidence.

G5 receiver qualification remains separate from software receiver support. G3 receiver-impact admission remains blocked until the required G5-qualified receiver receipt, source and runtime identity, powered sample design, and reviewer authority are valid for the exact receiver and waveform.

Native Sionna PHY or RT work is explicit and host-bound. Production D1 is denied unless the existing D1 gate authorizes the exact request. A missing prerequisite yields a blocked scientific disposition rather than a narrower inferred qualification.
