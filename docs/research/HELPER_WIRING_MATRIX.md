# Helper-to-canonical-route wiring matrix

This is a source-audited increment for `PKG00-003`, not a complete repository
helper inventory. Rows identify helpers that must reach a canonical workflow;
an API's existence or a unit test alone does not count as wiring. Scientific
qualification remains separate from software routing.

The generated [`HELPER_WIRING_INVENTORY.json`](HELPER_WIRING_INVENTORY.json)
indexes exported top-level functions from `datasets`, `evaluation`,
`experiments`, `integrations.sionna`, `propagation`, and `receivers`, with
same-module and direct import/call sites from the source trees, scripts,
`loslab` consumers, and tests, with separate production/test references and
source hashes. It is a syntactic lead list only:
it cannot infer semantic canonical routes, dynamically dispatched calls,
indirect/re-exported use, or APIs omitted from package `__all__`. The 2026-11-12
snapshot contains 254 functions: all 185 functions with detected local or
imported production callsites now have explicit source-audited route entries;
69 have no direct production callsite detected; all 69 have direct test
references. Fourteen no-production-caller functions are named exactly in a
governing plan/backlog. Test references establish exercised API behavior, not
production wiring. The frequency-dependent link-budget, TX-IQ and SINR helpers
now have bounded routes. These counts do not establish that the 69 functions
are dead or that documented routes cover every
runtime path.

Regenerate and compare it with:
`./.venv/bin/python scripts/audit_helper_wiring.py` and
`./.venv/bin/python scripts/audit_helper_wiring.py --check`.
