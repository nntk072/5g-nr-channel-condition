# 5G NR Channel Condition Agent Constitution

This repository is a 5G NR channel-condition research system. Agents may implement bounded software work from the active engineering queue while preserving the repository's scientific authorities and evidence boundaries.

## Authority

Use authority in this order.

1. Signed or frozen scientific protocols and exact normative contracts.
2. Current source and tests.
3. `docs/research/REQUIREMENT_LEDGER.json` and `docs/research/EXECUTION_QUEUE.md`.
4. This constitution and `.agents/rules/`.
5. `.agents/domain_maps/`.
6. Platform adapters under `.codex/` and `.claude/`.
7. Reviewed task cards.

A lower layer may narrow work. It may not weaken a higher layer.

## Scientific invariants

- Geometric LOS and path-oracle truth remain target or evidence data and never become deployed classifier inputs.
- TDL, CDL, and scenario LOS metadata are not geometric LOS proof unless an approved contract explicitly establishes that meaning.
- Signed split, lineage, scene, trajectory, receiver-view, noise, and parent-child boundaries remain intact.
- Phase gauge, delay reference, carrier alignment, antenna-port, and polarization semantics remain explicit.
- Native Sionna PHY or RT behavior requires evidence on the selected host. Mock and analytical fixtures establish software behavior only.
- Engineering status and scientific qualification status are independent. Software `PASS` never promotes G0-G8, G5, or G3.
- G3 receiver-impact admission requires the exact accepted G5 receiver evidence and the task-specific powered design required by the governing contract.
- Retained negative G4 and City43 evidence remains visible and cannot be replaced by a more favorable cohort.
- Production D1 RT, broad native sweeps, advanced training, and publication claims require their existing authorizations.
- Asset research permission and public redistribution permission remain separate.

## Engineering rules

Preserve unrelated dirty work, active jobs, logs, checkpoints, and evidence. Inspect current source and callers before changing behavior. One named writer owns each mutable file for a task. Use focused verification during implementation and retain exact command outcomes. Never fabricate a passing gate, treat a skipped gate as passing, or infer scientific validity from software tests.

Operational agent state belongs under ignored state roots. Existing `artifacts/`, `experiments/runner.py`, split policy, and `compute/resource_budget.py` remain the semantic owners of scientific artifacts, experiment execution, partitioning, and scientific resource estimation.

Do not commit, push, merge, rerun remote workflows, delete evidence, cancel jobs, or launch native scientific work without the authorization required by the active task and repository policy.
